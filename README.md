#Daily Expense Tracker
A simple Python application to track daily expenses using a text file.

##Features
*Add expenses
*View saved expenses
*Stores data in expenses.txt
*Handles file errors using exception handling
##Technologies Used
*Python 3
##How to Run
python expense_tracker.py
##Project Structure

│
├── expense_tracker.py
├── expenses.txt
└── README.md```
